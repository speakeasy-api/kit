The local deterministic scenario is mechanical conformance only. It uses a disposable copy of the
actual current Kit checkout and an HTTP/SSE mock behind the real OpenAI AgentKit adapter. The copy
preserves contained symlinks and rejects escaping links; Kit's one pinned documentation symlink is
then replaced by a regular file whose contents are the link target path bytes because managed edit
workspaces intentionally reject symlink entries. It no longer has mode-120000 symlink semantics and
no target is followed. The scenario then
traverses the M001 capability kernel and M004 native dispatcher. Exactly two debug completions cover
the edit's baseline and staged checks. The explicit `kit_check` and `kit_run` calls then terminate as
unavailable because there is no production executor. This is not the all-six-success claim and is
not G04 production evidence.

The dogfood scenario is a separate black-box Cargo package. Its dependency metadata has no Kit
library dependency, it does not
open daemon-private files, and discovers the workspace only through public `project` and `repo
status` surfaces. It correlates the provider's exact `kit_edit` call ID to the native operation/result
ID and uses only that result for revision, exact Git diff bytes, events, verification, feedback,
artifacts, and restart recovery. Every reachable artifact reference is opened before and after
restart. Direct API edit, failed-check abort, approval denial, and cancellation are tested separately.
