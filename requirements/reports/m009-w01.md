## Hook Contract

The Agentkit overlay adds one fallible post-validation checkpoint hook. With a hook installed, a dirty
mutator pass writes a copy-on-write candidate, transcript invariants validate before the callback, and
only an authoritative `Committed` result promotes the exact candidate before model dispatch. A clean
pass allocates no candidate and retains the existing path. Whole-transcript compactors use
`TranscriptCursor::replace` to avoid cloning a value they immediately replace.

The durable host supplies a non-cloneable checkpoint cursor containing attempt ID, attempt fence,
unique driver lease ID, durable-head sequence, and next operation sequence. The callback also receives
the exact base and candidate transcripts and expected previous durable-head sequence. These values are
the required CAS and digest inputs; Agentkit does not mint Kit authority. A checkpoint-enabled Agent
starts at most one driver. Kit's existing attempt-owned model adapter remains the dispatch fence on
clean passes.

Checkpoint outcomes are explicit: `Committed`, `NotCommitted`, and `Unknown`. A returned unknown or a
dropped callback future retains the same operation ID, base, candidate, turn, and original cancellation
checkpoint. The next call reconciles that exact operation before dispatch. Cancellation wins before
initial submission and after authoritative resolution, including a resolved-approval race, but cannot
silently discard an ambiguous durable write.
