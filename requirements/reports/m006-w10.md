## Canonical Contract

`CanonicalResult` stores immutable structured JSON separately from presentation. Schema version 1 has
a private fixed wire status, canonical object ordering, a 64 KiB serialized bound, and a
domain-separated SHA-256 digest over the schema version and exact canonical bytes. Decoding checks the
version before the v1 wire shape, rejects duplicate and unknown keys, rejects noncanonical bytes, and
round-trips accepted bytes and digests exactly. A hard-coded golden byte vector and digest protect the
wire contract from accidental drift.

The status matrix requires content only for success, an error code only for nonsuccess, charging for
success and failure, no charging for approval or cancellation states, and explicit charging for an
unknown outcome. Error codes, artifact counts, artifact syntax, and duplicate references are bounded
and validated. Artifact references are sorted so input order cannot change canonical bytes.

## Provenance And Nested Calls

Every result carries invocation and optional parent invocation IDs, principal, immutable binding,
capability identity, schema digest, authorization and grant snapshot digests, trace, idempotency key,
and remaining budget. Nested calls additionally require bounded delegation provenance and reject a
self-parent relationship. Direct calls reject nested-only fields. These are immutable value
invariants; only an authoritative broker may mint the values in a live invocation.

## Bounds And Presentation

Both byte decoding and in-memory construction enforce depth and node limits before serialization.
In-memory rejection tears down hostile deep values iteratively, avoiding recursive-drop stack
exhaustion. Serialization uses a capped writer, and presentation has a separate 16 KiB serialized
bound. A presentation is bound to one canonical-result digest and cannot alter canonical bytes or the
canonical digest. Known internal encodings are accepted; TOON metadata is fixed to Working Draft
`3.3` without claiming that a TOON encoder or its conformance vectors have shipped.
