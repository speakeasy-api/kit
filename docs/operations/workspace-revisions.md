# Managed workspace revisions

Managed workspace revisions are implemented on Linux and macOS. Other targets expose the same API but return the typed `RevisionError::Unavailable` result when a workspace is opened.

## Authority and identity

Every public revision read performs bounded foreground reconciliation. A revision token is an opaque BLAKE3 binding of a random owner epoch, a monotonic sequence, and the canonical content digest. The token does not expose the sequence. The process owning a workspace holds an exclusive lock on the opened workspace-root inode for its lifetime; managers in that process share the owner through a process-global registry, while a foreign process receives typed busy. Each ownership takeover rotates the epoch before serving a revision, including unchanged restarts and replay of both durable metadata files. Metadata persists the owner boot nonce and process-start identity.

`ManagedWorkspace::mutation_guard` takes the shared transaction operation lock and retains the revision-state lock for its lifetime. It reconciles only after both locks are held and validates the caller's expected revision before returning. Guard-bound consumers can reconcile again without dropping the transaction boundary, so stale authorizers and capabilities fail at issue or consumption.

A scan is accepted only when a native kernel mutation fence and two descriptor-relative traversals agree. The fence uses inotify on Linux and kqueue vnode events on macOS. It watches each parent before enumeration, then every opened directory and file, retains all registrations through the traversal, and validates descriptor identities. Any write, attribute change, create, delete, rename, watch loss, or queue overflow rejects the attempt; inability to register the complete tree returns typed unavailable. Equal digests without a clean event fence are not authority. Both traversals stream file bytes through a fixed 64 KiB buffer. Revision-only operations retain no file bytes; `read_file_range_before` retains only its capped byte or line selection and computes line coordinates without a newline-offset collection. Metadata snapshots retain complete content only within explicit per-file and aggregate bounds while still streaming every file for digest, NUL, and UTF-8 classification. File bytes, executable modes, paths, entry kinds, and empty directories are included. Every snapshot and read checks the requested token against the accepted scan, so a concurrent change produces a stale-revision or bounded scan error rather than a torn success.

## Metadata

Revision metadata must be outside the workspace. Custom locations reject lexical workspace paths, symlinked path components, symlink targets, and non-regular or multiply linked files. The metadata parent is opened once without following symlinks; lock, load, temporary creation, rename, cleanup, and directory synchronization remain relative to that handle even if its pathname is replaced.

Same-process managers serialize scans and metadata updates through their shared lifetime owner. State is published by synced temporary-file rename and mirrored to the retained lock-file guard. Metadata is outside the workspace descriptor traversal and never contributes to the content digest.

## Bounds and polling

Foreground scans and polling hints enforce entry-count, aggregate name-byte, content-byte, depth, and memory limits while enumerating. Their elapsed-time limit is a cooperative deadline checked between filesystem syscalls; it does not interrupt a blocked syscall or claim a hard wall-clock bound. The foreground deadline, content-byte budget, and deterministic logical memory budget are shared by both authoritative traversals. Each requested heap allocation is charged 64 bytes of container/allocation overhead plus payload rounded to 64-byte slabs through 4 KiB and to 4 KiB pages above that. Ordering, snapshot-entry, and macOS watch vectors start with `max(1, floor(4096 / size_of(T)))` elements and double their logical capacity; every replacement buffer's complete requested payload is charged before growth, so cumulative charges also cover the replaced storage. The operation budget covers name ownership, ordering and path storage, watch retention, bounded snapshot content, selected range storage, and every requested vector growth before allocation. Fixed digest, mount identity, C path, and 64 KiB streaming buffers allocate no heap storage. Allocator spare capacity is never consulted for authority.

The polling thread is only a bounded dirty hint and is never authoritative. The per-scan native event fence and foreground reconciliation remain authoritative even when no polling hint was observed. Periodic background reconciliation uses the same bounded primitives. Shutdown wakes the polling condition variable, interrupts bounded traversal, and joins the retained thread handle.

The conformance suite includes concurrent-manager and concurrent-subprocess coverage. The recorded local validation environment must identify the platform actually run; Linux support is not asserted as tested by a macOS run.
